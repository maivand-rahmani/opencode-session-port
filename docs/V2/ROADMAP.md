## 1. How to read this roadmap

- Each task is a checkbox with a stable ID, a status, dependencies, acceptance criteria, and document references.
- **Status labels:** `Completed` (`[x]`, with evidence); `In progress` (unchecked, with an explicit status note); `Not started`; `Blocked` (with the blocking dependency named); and `Unverified` for claims lacking evidence. No task is `In progress` until the owner authorizes implementation lanes (the 2026-10-18 M0 exception authorized the CI-01/CI-02 lanes; the 2026-10-19 direction authorizes independent local implementation for M1 and beyond while preserving every technical gate; §0).
- **Evidence discipline:** acceptance criteria do not claim results; results are recorded with labels (synthetic test / host test with named host+version / unverified) and platform, per [AGENT_RULES.md](AGENT_RULES.md) §5.
- **Numbering:** every task ID is defined in §3 of this file; §4 lists the gate subset (the gate overview in [ARCHITECTURE.md](ARCHITECTURE.md) §9 and [AGENT_RULES.md](AGENT_RULES.md) §8 is a subset, not an exhaustive ID list). IDs are stable and are not renumbered; earlier provisional labels from draft revisions of the companion documents are superseded.
