## Required invocation

The program is import-safe. With no arguments, or with any missing/unknown flag, it exits
before loading the native module or touching the store. All three flags are required:

```text
probe.ts --run-synthetic-keyring-probe --run-id <canonical-uuid> --deadline-ms <ms>
```

`--deadline-ms` must be an explicit integer in the inclusive range `1000..120000`. The
probe installs an internal watchdog that hard-exits on deadline with outcome `timeout`.
That exit makes **no rollback or cancellation claim** and can leave an uncertain synthetic
entry. The operator must also run it under an outer process timeout; the internal watchdog
is not a cleanup mechanism.

## Bounded sequence

1. Dynamically import the candidate **after** flag validation.
2. Construct the adapter with `maxSecretBytes = 32` and the actual `AsyncEntry`
   constructor.
3. Read only the exact derived pair and require `null` before any mutation. A non-null
   precheck fails without mutation, write, or delete.
4. Generate one 32-byte random synthetic secret in memory; write it to the exact pair.
5. Read the exact pair and compare in memory with the generated bytes.
6. Only after an exact match, delete the exact pair and read it again, requiring `null`.
7. On success, report fixed booleans/length only and exit 0.

No retries, enumeration, arbitrary entries, environment secrets, or production credentials
are used. On timeout or an uncertain native mutation, the probe does not blindly delete or
retry and retains the exact pair for manual review. Exact-entry cleanup in `finally` is
attempted only when the write was proven settled, the precheck was absent, and no delete
was attempted. Once a delete is attempted, an anomalous final read is retained rather than
deleted again.

## Result and exit codes

The JSON result contains `runId`, fixed outcome/stage strings, fixed booleans, and
`secretLength: 32`. It never contains secret bytes, service/account names, native error
text, environment data, or arbitrary identifiers.

| Exit | Meaning |
| --- | --- |
| `0` | Pass: precheck absent, write settled, exact readback, delete settled, final absent. |
| `1` | Failure or usage: no pass. |
| `2` | Internal deadline watchdog fired; no rollback/cancellation claim. |
| `3` | Mutation outcome uncertain; retain the exact pair for review. |
